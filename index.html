Algorithm (pseudocode)

SkipList-Search(L, key): x ← header
  for i ← L.level downto 0: while x.fwd[i] ≠ NIL and x.fwd[i].key < key: x ← x.fwd[i]
  x ← x.fwd[0]; return x if x.key = key else NIL

Random-Level(p, Max): lvl ← 0; while Random() < p and lvl < Max: lvl++; return lvl

SkipList-Insert: find update[]; if key exists, update value; else
  lvl ← Random-Level; raise L.level if needed; splice new node at levels 0..lvl

SkipList-Delete: find update[] and x; unlink x at each level; lower L.level while top level empty

AVL-Insert(T, key): BST insert, then Rebalance(T) on the way back up
Rebalance(z): update height; b ← h(left) − h(right)
  if b > 1: (LR case: rotate left child) rotate right
  if b < −1: (RL case: rotate right child) rotate left
